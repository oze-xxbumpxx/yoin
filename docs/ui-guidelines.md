この文書は、2026-11-22〜23に大関さんと決めた見本の画面を、画面を作る人（Devin）がそのまま使える値と決まりにしたものである。
問いと選ばなかった案は`docs/discussions/first-slice.md`にある。

見本の画面はClaude Designで作った（大関さんだけが開ける）。同じ画面の書き出しを`docs/design-assets/screens/`に置く。
書き出しは券の色を既定のアーティストの色（#C2185B）にしてある。文言とデータは見本で、最初の1本の要件ではない。

## 色

端末の設定（`prefers-color-scheme`）に合わせて、暗い表示と明るい表示を切り替える。部品の形・間・書体は両方で同じにし、色の値だけを入れ替える。
色はCSSの変数にし、画面のコードに色の値を直接書かない。

| 役目 | 変数 | 暗い表示 | 明るい表示 | 使う所 |
| --- | --- | --- | --- | --- |
| 地 | `--bg` | #121212 | #F7F5F1 | 画面の地。明るい表示は紙の券に合わせて真っ白にしない |
| 面 | `--surface` | #1F1F1F | #FFFFFF | カードと一覧の面 |
| 上の面 | `--raised` | #2A2A2A | #ECE9E3 | 絞り込み、ほかのボタン |
| 文字 | `--text` | #FFFFFF | #121212 | 本文 |
| 弱い文字 | `--text-sub` | #B3B3B3 | #6B6B6B | 説明、会場。白い地でも4.5:1以上 |
| 差し色 | `--accent` | #F5B83D | #F5B83D | 押せる所の地。上の文字は#121212 |
| 差し色の文字 | `--accent-ink` | #F5B83D | #9A6200 | 地に琥珀の文字を置くとき。明るい表示で#F5B83Dのままだと読めない |
| 差し色の面 | `--accent-soft` | #3A2A10 | #FFF0D1 | 次の期限の帯 |
| 注意 | `--danger` | #F3727F | #D93A4A | 期限切れ、送れなかった端末 |
| 余韻の薄れる先 | `--fade-to` | #1C1C1C | #ECE9E3 | 行った公演の券の色が日ごとに近づく色 |

差し色は、押せる所・選んでいる印・次の期限だけに使い、飾りに使わない。

### アーティストの色

券の色は、アルバムのジャケットの代わりにアーティストの色で塗る。次の12色から、アーティストの名前で1つを決め、あとで選び直せる。
自由な色にしないのは、券の上の白い文字を4.5:1以上で読めるようにするためである。12色は暗い表示と明るい表示で同じ。

#C2185B、#1565C0、#2E7D32、#6A1B9A、#E65100、#00838F、#AD1457、#283593、#558B2F、#4527A0、#BF360C、#00695C

券のグラデーションや文字の色は、アーティストの色から次の計算で作る。`t`が正なら白へ、負なら黒へ寄せる。

```ts
function shade(hex: string, t: number): string {
  const n = parseInt(hex.slice(1), 16);
  const rgb = [n >> 16, (n >> 8) & 255, n & 255].map((v) =>
    Math.round(t > 0 ? v + (255 - v) * t : v * (1 + t)),
  );
  return `#${rgb.map((v) => v.toString(16).padStart(2, "0")).join("")}`;
}
```

| 名前 | 計算 | 使う所 |
| --- | --- | --- |
| 明るい端 | `shade(色, 0.25)` | 券のグラデーションの始まり |
| 中 | `shade(色, -0.18)` | 半券の地 |
| 暗い端 | `shade(色, -0.32)` | 暗い表示の券のグラデーションの終わり |
| 最も暗い | `shade(色, -0.5)` | 暗い表示の公演の画面の上の地 |
| 券の文字 | `shade(色, 0.85)` | 券の上の大きな値 |
| 券の弱い文字 | `shade(色, 0.72)` | 券の上の英字の小見出し |

暗い表示の券は`linear-gradient(150deg, 明るい端, 色 50%, 暗い端)`にする。
明るい表示の券は暗い端を使わず、明るい端からアーティストの色までのグラデーションにし、半券もアーティストの色のまま暗くしない。
影は、暗い表示では次の期限と次の公演だけ琥珀の光をまとい、明るい表示では薄い茶色の影にする。

## 文字

和文は端末の書体を使う（iPhoneはヒラギノ角ゴ）。日付・時刻・英字の見出しだけFigtreeにし、英数字だけを読み込む。
太さは700と400の2段にし、日付と時刻の大きな数字だけ800にする。

| 用途 | 大きさと太さ |
| --- | --- |
| 見出し | 24px / 700 |
| 小見出し | 20px / 700 |
| 一覧の行の題 | 15px / 700 |
| 本文 | 15px / 400 |
| 説明・会場 | 13px / 400、弱い文字 |
| 券の日付と時刻 | Figtree 800 |

## 形と間

- ボタンと絞り込みは角丸999px、丸く押す所は50%、カードとジャケットは6px、帯と面は8px。
- 間は8pxを単位にし、画面の左右は16px。
- 枠線は使わず、面の明るさで分ける。影を付けるのは浮かぶもの（ダイアログ）だけで、`0 8px 24px`の黒50%。
- 押せる所は高さ44px以上。

## 部品

- 主なボタンは差し色の丸い棒で、1画面に1つ。ほかのボタンは枠だけにする。
- 絞り込みは、選んでいるものを差し色、ほかを上の面の色にする。
- 申込の状態は、申込済み・当選・入金済み・落選・期限切れの札で出す。期限切れは注意の色にする。
- 次の期限の帯は、下のタブの上に常に出す。期限が無ければ出さない。左に残り時間の輪、右に半券の切り取り線を置く。
- 通知先が無い、または送れなかった端末があるときは、注意の色の印と「通知先」への行き先を出す。

## yoinだけの部品

### 半券のカード

公演と申込のカードは、紙のチケットの作りにする。各欄の中身は`docs/design-assets/screens/ticket-anatomy.png`にある。

- 左の券面に、英字の小さな見出し（`LIVE TICKET`、`DATE`、`OPEN`、`START`、`SEAT`）と大きな値の欄を細い線で区切って並べる。右上に通し番号（例 `No. 0118-0042`）を置く。通し番号は公演の日付と申込の番号から作る飾りで、データには持たない。
- 右の細い欄を半券にし、日付か残り時間、状態のはんこを置く。
- 券面と半券のあいだは点のミシン目にし、上下に半円のくぼみを入れる。くぼみは地の色で円を描かず、CSSの`mask`で券を切り抜く。描いた円は地の色と合わず浮くため（2026-11-23 大関さんの指摘で直した）。
- 申込の券面のSEATには、申込の「座席・整理番号」の欄を出す。この欄は最初の1本で申込に足す（`docs/discussions/first-slice.md`の「券面に整理番号を出すか」）。

### 余韻

行った公演は、ホームの「行った公演」の棚に半券の形で並ぶ。券の色は、公演の日から日がたつほど、アーティストの色から余韻の薄れる先（`--fade-to`）へ近づく。

### ペンライトの光

次の期限と次の公演のカードだけ、琥珀の光（暗い表示）をまとう。残り時間は輪で減らす。
公演の残りが7日を切ったら、公演の画面に日・時・分・秒のカウントダウンと7つの目盛りを出す。

### 仲間の輪

グループは、メンバーの色を並べた輪で表し、真ん中に人数を書く。

## 文言

案内や結果の文はです・ます調にし、ボタンは短い動詞にする（「保存」「参加する」「入金済みにする」）。
この決まりは`docs/discussions/first-slice.md`の「画面の文言を、です・ます調にするか」で仮決定で、要件定義書（`docs/requirements/first-slice.md`）の承認で確定する。

## アプリのアイコン

ホーム画面のアイコンは、重なる2枚の半券に夕焼けのグラデーションをかけた形にした。書き出しは`docs/design-assets/icon/`にある。

| ファイル | 使う所 |
| --- | --- |
| `apple-touch-icon-180.png` | iPhoneのホーム画面（`apple-touch-icon`） |
| `icon-192.png`、`icon-512.png` | Web App Manifestの`icons`（`purpose: any`） |
| `icon-maskable-192.png`、`icon-maskable-512.png` | Web App Manifestの`icons`（`purpose: maskable`） |
| `yoin-icon.svg`、`yoin-icon-maskable.svg` | 書き出しの元 |

ホーム画面の名前（manifestの`name`と`short_name`）は「yoin」にする（`docs/requirements/first-slice.md`のF-48）。
